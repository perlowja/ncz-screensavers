--- end-to-end shim correctness check (linking the ACTUAL deployed .o) ---
This is a stricter check than the standard link/ldd/nm bar: a small
test program (tools/test-gluScaleImage-from-build.c) is linked against
build/timetunnel_gles3.p/src_xscreensaver_compat.c.o (the exact .o
file that gets linked into the deployed binary) and exercises the
gluScaleImage function in 14 distinct cases. ALL 14 tests pass:

  ok:   identity 4x4->4x4 returns 0
  ok:   identity 4x4->4x4 preserves bytes
  ok:   2x2->4x4 upsize returns 0
  ok:   2x2->4x4 bilinear matches hand-computed expectations
  ok:   10x10->8x8 returns 0
  ok:   10x10->8x8 uniform red -> all dst pixels red
  ok:   GL_RGB input rejected with GLU_ERROR
  ok:   GL_RGB input did not write dst
  ok:   GL_UNSIGNED_SHORT input rejected with GLU_ERROR
  ok:   GL_UNSIGNED_SHORT input did not write dst
  ok:   srcW=0 rejected with GLU_ERROR
  ok:   dstH=0 rejected with GLU_ERROR
  ok:   NULL dst rejected with GLU_ERROR
  ok:   NULL src rejected with GLU_ERROR

This covers: identity-resize (memcpy fast path), bilinear upsize
with hand-computed pixel-by-pixel expectations, the timetunnel
actual call shape (non-Po2 -> Po2 uniform source), all rejection
paths (unsupported format / type / dimensions / NULL). Build & run:
  gcc -Wall -Wextra -O2 \
      -o /tmp/test-gluScaleImage-from-build \
      tools/test-gluScaleImage-from-build.c \
      build/timetunnel_gles3.p/src_xscreensaver_compat.c.o \
      build/timetunnel_gles3.p/src_gles3_compat.c.o \
      -lEGL -lGLESv2 -lm
  /tmp/test-gluScaleImage-from-build
